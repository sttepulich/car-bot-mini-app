ШАГ 1: Откройте репозиторий
────────────────────────────
https://github.com/sttepulich/car-bot-mini-app

Войдите в свой GitHub аккаунт (sttepulich)


ШАГ 2: Загрузите index.html
────────────────────────────
1. В списке файлов найдите папку "mini_app"
2. Нажмите на неё
3. Найдите файл "index.html"
4. Нажмите на файл
5. Нажмите значок карандаша ✏️ (Edit this file) справа вверху
6. Откройте файл index.html из этой папки в блокноте
7. Выделите ВСЁ содержимое (Ctrl+A)
8. Скопируйте (Ctrl+C)
9. Вернитесь в браузер GitHub
10. Выделите весь текст в редакторе (Ctrl+A)
11. Вставьте скопированное (Ctrl+V)
12. Нажмите зеленую кнопку "Commit changes..." справа вверху
13. В окне напишите: "Update Mini App - full version"
14. Нажмите "Commit changes"

✅ Готово! Первый файл загружен!


ШАГ 3: Загрузите app.js
────────────────────────────
Повторите те же действия для файла app.js:

1. В папке mini_app найдите "app.js"
2. Нажмите на файл
3. Нажмите ✏️ Edit
4. Откройте app.js из этой папки
5. Ctrl+A → Ctrl+C (скопировать всё)
6. В браузере: Ctrl+A → Ctrl+V (заменить всё)
7. Commit changes
8. Сообщение: "Update app.js - full functions"
9. Commit

✅ Второй файл готов!

Q: Не могу найти кнопку Edit (✏️)
A: Убедитесь что вы вошли в свой аккаунт GitHub

Q: Пишет "You can't edit this file"
A: Значит репозиторий не ваш. Нужно загрузить на свой GitHub

Q: После загрузки ничего не изменилось
A: Подождите 2-3 минуты и обновите страницу (Ctrl+F5)

Q: Mini App показывает ошибку
A: Проверьте что все 4 файла загружены полностью

Q: VIN декодер не работает
A: Проверьте что vin-decoder.js загружен!
